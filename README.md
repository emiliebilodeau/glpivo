# GLPivot

Suivi des injections, du poids, des symptômes et de la progression.

Application web installable (PWA). Les données restent sur l'appareil de l'utilisatrice et, si elle l'active, dans un dossier caché de son propre Google Drive (`appDataFolder`). Aucun serveur ne reçoit de données.

**Avertissement :** GLPivot est un outil d'information et de suivi général. Il ne fournit aucun avis médical, diagnostic ni recommandation de traitement ou de dose.
